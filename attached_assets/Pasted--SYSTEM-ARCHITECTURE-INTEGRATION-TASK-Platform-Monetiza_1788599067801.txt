### 2. BACKEND API ENDPOINTS & BUSINESS LOGIC (Express API - Port 8080)

Create/Protect the following routes under `/api/admin` with `requireAdmin` middleware (`role === 'admin' || role === 'super_admin'`):

1. **`GET /api/admin/analytics/revenue`**:
   - Calculates Total Platform Revenue, Monthly Revenue, Pending Escrow Funds, and Breakdown per `fee_type`.
2. **`GET /api/admin/escrows` & `POST /api/admin/escrows/:id/resolve`**:
   - Lists all active/disputed escrows.
   - Allows Admin to resolve disputes (Refund Buyer vs Release to Founder) and deduct the platform fee automatically.
3. **`GET /api/admin/users` & `PATCH /api/admin/users/:id/status`**:
   - Lists registered users with options to change roles or suspend/ban accounts.
4. **`GET /api/admin/audit-logs`**:
   - Fetch recent system audit logs with pagination and filters.
5. **`GET & PATCH /api/admin/settings`**:
   - Retrieve and update platform fee percentages in real-time.
